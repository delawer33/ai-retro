# Число «перепроверить» в топ-10 считается по сходству формулировок, а не по оценке модели

PRD просит для каждого паттерна из топ-10 показать, сколько эпизодов модель могла отнести к нему
ошибочно. Группировка возвращает только названия и номера эпизодов, уверенности по эпизодам в ней нет.

Эпизод помечается к перепроверке, если сходство его сути с названием паттерна (SequenceMatcher)
ниже порога. Это прокси: он реагирует на формулировки, а не на смысл, поэтому «не используй X» и
«избегай X» могут попасть в отметку, а несвязанные сути с похожими символами — нет. Рассмотрели
поле уверенности по каждому номеру в схеме группировки: модель выдаёт его без калибровки, а схема и
промпт усложняются. Отложено до тех пор, пока шум прокси мешает критерию остановки.

## Consequences

- Число в отчёте — подсказка, где смотреть глазами; отчёт так и говорит.
- Если прокси мешает, замена — уверенность по номерам в схеме группировки; поменяются `JSON_SCHEMA`,
  `Pattern` и `recheck_count`.
