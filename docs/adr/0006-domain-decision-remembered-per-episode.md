# Решение модели по области помним флагом `domain_by_model` на эпизодах

Scratch-беседа с областью «иное» перезапрашивалась у модели при каждом `scan`: по записи в базе
нельзя было отличить законное «иное» от «иное» по сбою. Нужен признак, кто поставил область.

Добавлена колонка `episodes.domain_by_model` (миграция 0003): истина, если область поставила
модель. `scan` не переспрашивает беседу с этим флагом; scratch-беседа с «иное» без флага (сбой
или запись старого кода) пересматривается. Рассматривали отдельную таблицу решений по беседам:
она чище по нормализации, но область уже хранится на эпизодах, и вторая таблица добавила бы
join и расхождение источников ради одного булева значения.

## Consequences

- Законное «иное» не тратит вызовы модели на каждом `scan`.
- Чтобы переспросить модель принудительно, флаг надо сбросить в базе (отдельной команды нет).
- Неопознанная модель (`UnrecognizedModelError`) прерывает `scan` до записи областей, поэтому
  «иное» по этой причине в базе не появляется.
