# Реплика из одной встроенной команды — не эпизод

ADR 0012 убрал у встроенных команд (`/compact`, `/model`, `/clear`, `/login`…) признак «вызов
скилла», но оставил их эпизодами. На реальных данных голый `/compact` попадал в классификатор,
и модель принимала его за поправку «отвечай компактнее»: 5 из 13 эпизодов топ-паттерна были
такими. Предложение в CLAUDE.md строилось на мусоре.

Реплика, которая целиком — слэш-команда без SKILL.md (с аргументами или без), эпизодом не
считается: правило живёт в `conversations_to_episodes` рядом с остальными правилами фильтра
(ADR 0005). Слэш-команда с SKILL.md остаётся эпизодом с признаком (ADR 0012), её аргументы — обычная
реплика (ADR 0004). Прерывание и отказ перед выброшенной командой уходят признаком в
следующий эпизод, как и перед любой записью без текста. Старые эпизоды такой формы удаляет
пересмотр при `scan` (ADR 0011). Рассматривали исключать команды в классификаторе по списку
имён: список устарел бы с каждым релизом Claude Code, а наличие SKILL.md уже есть источник
истины.

## Consequences

- Эпизод может исчезнуть и у скилла, чей SKILL.md удалён с диска; пересмотр удалит его
  вместе с классификацией и метками эталона.
- Слэш-команда, которой нет на диске по ошибке (другой `--skills-dir`), тоже пропадёт.
