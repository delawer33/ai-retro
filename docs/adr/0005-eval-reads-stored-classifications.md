# `eval` берёт классификации из базы и дозапрашивает только недостающие

`scan` уже классифицирует эпизоды, в том числе эпизоды эталона. Повторный вызов модели на каждом
`eval` тратил бы подписку (ADR 0002) и давал бы разброс между прогонами без смены промпта.
`ai-retro eval` использует сохранённую классификацию текущей версии классификатора и вызывает
модель только для эпизодов эталона без неё; `--refresh` классифицирует эталон заново.

Версия классификатора включает sha промпта и модель (`classifier_version`), поэтому после правки
промпта сохранённые классификации не подходят и `eval` классифицирует эталон заново сам.

## Consequences

- Тесты вставляют метки и классификации в базу напрямую, модель не нужна.
- «Потолок» — доля совпадений первой метки человека с повторной вслепую; те же метрики, что у
  модели, считает один и тот же код (`evals/metrics.py`).
