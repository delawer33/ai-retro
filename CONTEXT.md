# Ai Retro

Анализ сессий Claude Code и поиск повторяющихся паттернов

## Language

Термины предметной области и их смысл здесь. Код, тесты, поля API и доки используют эти слова;
строка _Avoid_ перечисляет синонимы, которым нельзя просочиться обратно. Термин добавляется,
когда получает точный смысл в решении, а не заранее.
